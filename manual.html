1. 這是什麼工具

「技能（Skill）」是一段寫好的指示，讓 AI 每次都用同樣的流程與格式完成某件工作。本工具把你的一句需求描述（或一張參考圖片）變成完整的技能提示詞，複製後貼到 Claude、ChatGPT（自訂 GPT）、Gemini（Gem）就能建立技能。另外的「🔍 逆向工程」分頁，可以從一張圖或一段文字反推出能做出它的提示詞。

產出的 SKILL.md 長這樣：

---
name: user:social-post
description: 根據上傳的產品圖片或主題，自動生成符合指定社群平台風格的行銷貼文與 Hashtags。
---

# Social Post Generator

## Overview
這個技能協助使用者將產品圖片或核心賣點轉化為吸引人的社群行銷貼文。

## Instructions
1. 分析使用者上傳的圖片或產品主題。
2. 根據使用者指定的社群平台風格調整語氣：
   - **IG / Threads**：親切、活潑、多用表情符號與 Hashtags。
   - **Facebook**：專業、結構清晰、適合詳細介紹與引導點擊。
3. 結構應包含：吸睛標題、內文重點、行動呼籲（CTA）及標籤（Hashtags）。

2. 🧩 技能產生器：四個步驟

  1. 描述你要的技能：一句話說明要做什麼（可點 12 個範例）。可以拖曳、點擊或 Ctrl+V 貼上最多 4 張參考圖片，例如想要的輸出樣式、要處理的單據照片。
  2. 輸出設定：詳細程度（精簡＝像上面的範例；標準＝再加輸出格式與注意事項；完整＝再加輸入資料與範例）、回覆語言、語氣、name 前綴（user: 或無）、段落標題用英文或中文。
  3. 技能提示詞：按「⚡ 規則式產生」（免金鑰，內建 15 種技能類型）或「🤖 AI 產生」（需自備金鑰，會真的看圖）。右側切換平台分頁，框內可直接修改，按「📋 一鍵複製」。
  4. 技能內容微調：name、標題、description、步驟、輸出格式、注意事項、範例、對話開場白都能改，右側即時更新。步驟欄位每行一步，以「-」開頭的行會變成上一步的子項。

已經有 SKILL.md？直接貼進第 1 步的文字框按「規則式產生」，會自動解析，再切到 ChatGPT／Gemini 分頁就能轉成對應格式。

規則式會依關鍵字判斷技能類型：社群貼文、商品文案、Email 回覆、會議紀錄、翻譯潤稿、簡報大綱、課程教案、單據擷取、短影音腳本、程式碼審查、資料分析、履歷求職、企劃提案、圖片解讀，其餘歸為「自訂 AI 助手」。提到 IG、Facebook、Threads、LINE、小紅書、LinkedIn、YouTube、TikTok 會自動加上各平台的語氣說明；提到圖片或有上傳圖片時，會加入「先觀察圖片」的步驟。

3. 四種平台格式與貼到哪裡

分頁格式貼到哪裡
SKILL.md（Claude／通用）YAML 開頭（name、description）＋ Markdown按「⬇ 下載 Claude 技能 ZIP」，到 claude.ai「設定 → 功能 → 技能」上傳；Claude Code 放到 ~/.claude/skills/名稱/SKILL.md。ChatGPT、Gemini 也可以整段貼到指示欄位。
ChatGPT 技能有技能名稱與呼叫指令（例如 /social-post）的技能註冊文，含呼叫規則直接整段貼進 ChatGPT 對話（需開啟記憶），回覆「已記住技能」後，在任何對話輸入 /social-post 加內容就能叫出；最後附「改建成自訂 GPT」的填法。
Gemini 技能同上直接整段貼進 Gemini 對話，存到「已儲存的資訊」後用 /技能名稱 叫出；最後附「建立成 Gem」的填法。
通用 AI 技能同上Copilot、Grok、DeepSeek、Perplexity 等：貼成對話第一則訊息，同一個對話內用 /技能名稱 叫出；沒有長期記憶的 AI 換新對話要重貼，或貼到自訂指令欄位。

輸入 /skills 可以請 AI 列出它記住的所有技能。注意：ChatGPT、Gemini 的記憶有時只存摘要，步驟多的技能可能執行得不完整；要長期穩定使用，建議照輸出最後一段建成自訂 GPT／Gem，或貼到「專案」的指示。

name 前綴：選「user:」會輸出 name: user:social-post；Claude 官方規格的 name 只允許英文小寫、數字與連字號，若上傳 Claude 時出現格式錯誤，請改選「無前綴」。各平台介面名稱可能隨改版調整。

4. 🔍 逆向工程

看到一張喜歡的圖或一篇寫得好的貼文，想知道「要怎麼下提示詞才做得出來」，就用這個分頁。

  1. 放入素材：拖曳、點擊上傳，或直接 Ctrl+V 貼上截圖；也可以貼上一段文字（沒有圖片時就反推文字的寫作提示詞）。
  2. 選細節程度，需要時填「補充要求」（例如「保留構圖但改成水彩風」）。
  3. 按「🤖 AI 反推提示詞」。圖片會得到四種格式：通用中英對照、Gemini／ChatGPT 生圖、Midjourney（自動依原圖算 --ar 比例）、Stable Diffusion／Flux（標籤＋負面提示詞＋建議尺寸）。文字會得到中文、英文與結構化三種格式，主題相關內容會變成【變數】方便重複使用。
  4. 修改與複製：提示詞框可直接修改（每個格式分頁各自保留），按「📋 一鍵複製」。也可以改左下「解析細項」（主體、畫風、構圖、光線…）後按「🔁 依細項重組」。
  5. 「🧩 做成技能」會把反推結果帶到技能產生器，做成「以後都產出這種風格」的技能。

沒有金鑰？按「📝 產生反推指令」，複製這段指令貼到 ChatGPT 或 Gemini，並附上同一張圖片，一樣能得到反推提示詞。

5. 串接 AI 語言模型（BYOK）

在 ⚙ 常用設定選服務商、模型並貼上自己的 API 金鑰（自備金鑰 BYOK），技能產生與逆向工程共用。

服務商看圖取得金鑰
Gemini（Google AI Studio）✓aistudio.google.com → Get API key（有免費額度）
OpenAI✓platform.openai.com → API keys
Claude（Anthropic）✓console.anthropic.com → API Keys
OpenRouter✓（依模型）openrouter.ai → Keys，一把金鑰用多家模型
xAI Grok✓（Grok 4）console.x.ai
DeepSeek✕ 只支援文字platform.deepseek.com
自訂（OpenAI 相容）依模型本機 Ollama、LM Studio 等，填 API 網址（填到 /v1 即可），可不填金鑰
  • 可另填「自訂模型名稱」使用新推出的模型；按「🔌 測試連線」確認接得通。
  • 金鑰只存在你的瀏覽器，直接送到該服務商，不經過本站；費用由你的帳號支付。
  • 部分服務可能不允許瀏覽器直接呼叫（CORS），測試連線會提示。
  • 圖片會先縮小到最長邊 1536px 再送出，節省流量與費用。

6. 讓技能更好用的技巧

  • description 要寫清楚「做什麼」和「什麼時候用」，AI 才知道何時啟用這個技能。
  • 步驟寫成動作（分析、整理、列出、檢查），每步一件事。
  • 把輸出格式寫死（標題、表格欄位、字數），每次結果才會一致。
  • 在注意事項寫上「資訊不足先提問」「不編造數據」等限制，可以減少 AI 亂寫。
  • 建立後實際測試 2～3 次，回到第 4 步微調再更新。

7. ⚙ 常用設定與存檔

  • 常用設定：預設平台分頁、詳細程度、回覆語言、name 前綴、段落標題、逆向工程預設格式、外觀（亮／暗）、AI 服務商／模型／金鑰。「儲存」只存起來，「儲存並套用」同時改目前畫面。
  • 儲存專案下載 .json，可用「開啟專案」還原；歷史紀錄保留最近 20 筆（技能與逆向工程都有，圖片不存）；技能描述與內容會自動暫存。
  • 加入主畫面：按「📲 安裝」，即可像 App 一樣從桌面或手機主畫面開啟。

8. 使用警語

  • 本工具只產生文字提示詞，實際效果依各 AI 平台與模型而異，請先測試再正式使用，並自行檢查 AI 產出內容。
  • 使用 AI 功能時，文字與圖片會直接送到你填寫金鑰的服務商，費用由你的帳號支付；請勿上傳機密、個資或含他人臉孔的照片。
  • 逆向工程結果僅供學習與創作參考；他人作品的著作權屬原作者，請勿用來仿冒特定作品或做商業用途。
  • 建立的技能需遵守各平台使用政策，不可用於詐騙、冒充他人或產生違法內容。
  • 僅供教學、課程及個人使用，禁止未經授權公開發布、販售或商業化使用本工具。
